One line about the dumbest thing my agent did today, written to `/output/entry.txt`. The judges read entries two at a time and pick the funniest, truest line; the output is deterministic, with no clock, randomness or network calls.

## Run it

```sh
node --experimental-strip-types main.ts
cat /output/entry.txt
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory; it defaults to `/output`.
